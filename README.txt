WILDLIFE EXPLORER — VERSION 1

This is a starter prototype for a large animal database website.

HOW TO USE:
1. Open index.html in a web browser.
2. Use "Random Animal", "Browse all animals", or search.
3. Use "Add Animal" to create your own entries.
4. Animal entries are stored in this browser's local storage for this prototype.

IMPORTANT:
This is intentionally the small first version. For a 70,000+ species database, the next major step is moving the animal data from browser storage into a real database/backend and adding bulk import/export. That will let you manage a huge number of species safely.

The current two example photos are loaded from Wikimedia Commons URLs and are only starter examples.
